GPT Plus、Go、Pro 100 / 200 / 500 怎么选

按用量选，不按价格选。价格均为公开比价站 2026-11-15 的读数。

价格对照

  • ChatGPT Go：埃及区直充最低约 28.65 元，主流 29–41 元。
  • ChatGPT Plus：官方 20 美元/月；保质保量代充主流 115–129 元/月。
  • GPT Pro 100：官方 100 美元/月；市场 699–750 元。
  • GPT Pro 200：官方 200 美元/月；市场 1,399–1,500 元。
  • GPT Pro 500：官方 500 美元/月；市场 3,499–3,750 元。

怎么选

  • 轻度用、只想便宜试水：选 Go。Go 是低价档，适合先花小钱试用。
  • 每天都用、要完整 Plus 权益：选 Plus。这是走量最大的档位。
  • 写代码、跑任务量大，或每月 API 用量本身就接近 100 美元起步：再看 Pro 档。2026-10-28 起，Pro 每月会送等额 API 额度（100 / 200 / 500 美元），这是 Pro 的卖点，但不要为了额度硬上 Pro。

两个避坑点

  1. Go 和 Codex Go 是同一个订阅的不同叫法，不要当两个品重复买。
  2. Pro 200 如果报价明显低于官方价（200 美元约 1,334 元），先核实它到底交付什么，是低区、半价还是不同交付物，没核实不要下单。

售后通则

保质保量代充的质保期一般是 30 天，保“订阅掉了”，分“掉订阅补整月”和“掉订阅按剩余天数退差价”两档；封号不在质保内。下单前请逐字看清详情页的质保与退款规则。
