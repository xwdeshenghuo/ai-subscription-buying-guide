ChatGPT Pro 100 / 200 / 500 三档怎么选

按每月用量选档位，不按“越贵越好”选。价格为 2026-11-21 公开比价站读数。

三档是什么

  • Pro 100：官方 100 美元/月；Pro 200：官方 200 美元/月；Pro 500：官方 500 美元/月。
  • 2026-10-28 起，每档每月送等额 API 额度（100 / 200 / 500 美元）。这是 Pro 的卖点，但不要为了额度硬上高档。
  • 三档的模型权限相同，差别在用量和附送额度，不是谁比谁“更聪明”。

价格对照（2026-11-21，CardNav）

  • Pro 100：主流 671–921 元。本店 699 元，在售。
  • Pro 200：主流 1,099–1,149 元。本店 1,109 元，在售。

  • 本店三档均为卡密自动发货，质保 30 天（2026-11-21 核实）。

怎么选

  • 每月 API 用量本身接近 100 美元，或 Codex 用得多：看 Pro 100。额度刚好抵掉订阅费才划算。
  • 每月 API 用量接近 200 美元：看 Pro 200。
  • 每月用量真的到 500 美元量级，或团队共用：再看 Pro 500。只为“以防万一”买 500 是浪费。
  • 用量不大、只想用满血模型：Plus 就够了，不用上 Pro。

两个避坑点

  1. 低于官方价先问交付物：Pro 200 官方价 200 美元约 1,334 元，市场直充 1,099–1,149 元通常是低区官方充值到自己号；先核实是哪个区、充到谁的号，没核实不要下单。
  2. 先分清直充和成品号：直充是充到你自己的号，成品号是给一个现成账号，两者价格、KYC 要求和售后写法都不同，不能直接比价。
